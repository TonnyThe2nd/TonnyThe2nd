### 🚀 Projeto em destaque: Sistema Distribuído de Classificação de Imagens com IA

> Uma arquitetura completa que simula um ambiente real de microsserviços para inferência de imagens usando CNN, FastAPI, RabbitMQ e workers assíncronos, orquestrada com Docker Compose.

🔗 [Repositório do projeto](https://github.com/TonnyThe2nd/ia-distribuida) (coloque o link real aqui)

**Tecnologias utilizadas:**
- Frontend: Angular 21 + Angular Material
- Backend: FastAPI, Uvicorn
- Mensageria: RabbitMQ (broker)
- Workers: Python assíncrono (3 réplicas escaláveis)
- Deep Learning: TensorFlow / Keras, OpenCV
- Orquestração: Docker e Docker Compose

**Principais desafios superados:**
- Integração do Angular com Docker (hot reload, volumes anônimos, compatibilidade de binários com Alpine vs Slim)
- Comunicação assíncrona entre API e workers com filas
- Escalabilidade horizontal (`--scale worker=3`)
- Validação e upload de imagens no frontend (apenas JPG, JPEG, PNG)
